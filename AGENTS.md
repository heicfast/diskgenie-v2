# Agent instructions

Before coding, refactoring, reviewing, benchmarking, or changing UI/CI:

1. Read [`PRINCIPLES.md`](PRINCIPLES.md).
2. Read every linked principle for the affected area.
3. Check repository status and preserve unrelated changes.
4. Record the baseline, plan, commands, results, and workflow artifacts under
   [`codex/`](codex/README.md).
5. Run the relevant local gates in
   [`principles/08-quality-gates.md`](principles/08-quality-gates.md) before push.

Do not claim performance, parity, superiority, or release readiness without the
evidence required by the principles. Do not store credentials in the repository.
